# 风翼影视中央配置

本仓库保存「风翼影视」电视端统一读取的公开配置。修改配置文件后，支持中央配置同步的客户端可在联网检查时获取新配置，无需逐台输入地址，也无需重新安装 APK。

## 配置文件

编辑仓库根目录的 `config.json`。

| 字段 | 用途 |
| --- | --- |
| `schemaVersion` | 配置格式版本，当前为 1，请勿随意修改 |
| `version` | 配置递增版本号；每次发布新配置时加 1 |
| `updatedAt` | 最近修改时间（UTC） |
| `vodUrl` | 点播源/API 地址 |
| `liveUrl` | 直播源/API 地址 |
| `minAppVersion` | 最低支持的客户端配置版本 |
| `message` | 可选的更新说明 |

## 修改步骤

1. 打开 `config.json`。
2. 点击铅笔图标（Edit）。
3. 修改需要更新的字段，保留 JSON 格式。
4. 每次发布新配置，将 `version` 增加 1。
5. 点击 **Commit changes** 保存。

## 重要提醒

- 本仓库公开，任何人都可能读取配置内容。请勿填写密码、访问令牌、私人密钥或其他秘密信息。
- 只填写你确认可用且有权使用的 HTTPS 地址。
- 当前模板中的 `vodUrl` 和 `liveUrl` 为空；请填入你自己的真实地址。
- 只有安装支持中央配置同步功能的「风翼影视」版本，电视才会自动读取这里的配置。旧版 APK 不会因创建本仓库而自动获得该功能。


## APK 自动更新（OTA）清单

根目录新增 `updates.json`，专门描述客户端 APK 更新；它与 `config.json` 的点播/直播地址配置相互独立。

- `packageName` 必须与客户端安装包包名一致。
- `architectures.armeabi-v7a` 只发布 32 位 APK；`architectures.arm64-v8a` 只发布 64 位 APK。
- `versionCode` 必须大于电视当前安装版本，客户端才会提示更新。
- `apkUrl` 应指向正式发布的、与当前架构匹配的 APK。
- `sha256` 必须填写该 APK 的 SHA-256 校验值；客户端应在安装前校验。
- `mandatory` 表示是否为必须升级；普通更新应保持 `false`。
- `releaseNotes` 用于显示版本更新说明。

### 发布安全要求

1. 只发布使用同一正式签名证书签名的 APK。签名不一致时，Android 会拒绝覆盖安装。
2. 32 位和 64 位 APK 分别构建、分别计算 SHA-256，并分别填写对应架构节点。
3. 在 APK 构建、签名、架构和哈希验证全部通过后，才填写正式下载地址和版本号。
4. 当前 `updates.json` 是协议模板，版本号为 0、下载地址和哈希为空；这代表尚未发布 OTA 包，不会触发升级。
5. 客户端必须在下载后验证包名、版本和 SHA-256，并通过 Android 系统安装流程完成用户确认；不承诺所有电视都支持静默安装。

**注意：** 仅创建更新清单不会让旧版 APK 自动升级。客户端 OTA 检查、下载、校验和安装流程仍需在应用代码中实现。
