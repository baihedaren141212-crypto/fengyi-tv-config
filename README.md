# 风翼影视中央配置

本仓库保存「风翼影视」电视端统一读取的公开配置。修改配置文件后，支持中央配置同步的客户端可在联网检查时获取新配置，无需逐台输入地址，也无需重新安装 APK。

## 配置文件

编辑仓库根目录的 `config.json`。

| 字段 | 用途 |
| --- | --- |
| `schemaVersion` | 配置格式版本，当前为 1，请勿随意修改 |
| `version` | 配置递增版本号；每次发布新配置时加 1 |
| `updatedAt` | 最近修改时间（UTC） |
| `vodUrl` | 点播源/API 地址 |
| `liveUrl` | 直播源/API 地址 |
| `minAppVersion` | 最低支持的客户端配置版本 |
| `message` | 可选的更新说明 |

## 修改步骤

1. 打开 `config.json`。
2. 点击铅笔图标（Edit）。
3. 修改需要更新的字段，保留 JSON 格式。
4. 每次发布新配置，将 `version` 增加 1。
5. 点击 **Commit changes** 保存。

## 重要提醒

- 本仓库公开，任何人都可能读取配置内容。请勿填写密码、访问令牌、私人密钥或其他秘密信息。
- 只填写你确认可用且有权使用的 HTTPS 地址。
- 当前模板中的 `vodUrl` 和 `liveUrl` 为空；请填入你自己的真实地址。
- 只有安装支持中央配置同步功能的「风翼影视」版本，电视才会自动读取这里的配置。旧版 APK 不会因创建本仓库而自动获得该功能。
